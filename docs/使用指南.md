# 商业超体 使用指南

## 一、系统简介

**商业超体** 是一款 AI 驱动的商业诊断工具，通过多轮深度对话，帮助您挖掘商业底牌、构建护城河、锁定精准定位。

### 核心价值
- 发现您真正掌握的独占资源
- 挖掘客户的隐性痛点
- 制定可落地的商业模式

---

## 二、使用流程

### 第一步：开启诊断对话

点击「文件」→「新会话」，系统将自动开启一段新的商业诊断对话。

系统会以中文欢迎您，并提出第一个问题。

### 第二步：回答 AI 顾问的问题

系统会通过 **5 个阶段的追问**，帮您梳理商业模式：

| 阶段 | 核心问题 | 您的任务 |
|------|----------|----------|
| 1️⃣ | 您的独占资源是什么？ | 描述您独特的资源、渠道、方法论 |
| 2️⃣ | 客户不买的代价是什么？ | 分析客户痛点和购买障碍 |
| 3️⃣ | 您能交付什么？ | 确认时间、精力、利润边界 |
| 4️⃣ | 如何构建护城河？ | 分析竞争策略 |
| 5️⃣ | 生成商业蓝图 | 获得完整方案 |

### 第三步：观察右侧画布变化

在对话过程中，右侧的 **「动态商业画布」** 会实时更新：
- 显示您已挖掘出的独占资源
- 展示客户痛点分析
- 生成信任构建策略
- 预览商业蓝图

---

## 三、必须完成的工作

### ✅ 坦诚回答问题

这是最重要的事。AI 顾问会像老中医一样追问，您需要：

- **如实描述** 您的业务现状
- **深入思考** 每个问题，不要浮于表面
- **配合追问** 挖掘真正的商业底牌

### ✅ 完成至少 5 轮对话

通常需要 5-10 轮对话才能完成诊断。每一轮对话都在帮助系统更精准地理解您的业务。

### ✅ 填写关键信息

系统会提取对话中的关键信息，请确认并补充：
- 独占资源清单
- 客户痛点列表
- 交付模式选择

---

## 四、配置大模型（可选）

如果您希望使用真实的 AI 对话，需要配置 API：

1. 点击「设置」→「LLM API 配置」
2. 配置 **DeepSeek**（常规对话用）
3. 配置 **Kimi**（长上下文用）
4. 保存配置后重启应用

> 不配置也可以使用，系统会提供模拟回复。

## 六、常见问题

**Q: 我没有任何商业经验，能用这个系统吗？**

A: 可以。系统通过追问引导您思考，即使没有经验也能完成诊断。

**Q: 对话过程中可以中断吗？**

A: 可以。所有对话会自动保存，下次打开会继续。

**Q: 需要配置 API 吗？**

A: 可选。不配置时系统提供模拟回复，但建议配置以获得真实 AI 支持。

**Q: 诊断结果准确吗？**

A: 结果质量取决于您提供的信息。越坦诚、越深入，效果越好。

---

## 七、使用建议

1. **保持专注**：找一个不被打扰的时间段进行诊断
2. **深度思考**：不要敷衍每个问题，深入思考后再回答
3. **多次迭代**：可以多次对话，逐步完善您的商业蓝图
4. **结合实际**：诊断结果是起点，需要结合实际情况落地执行

---

## 八、快速开始

```
1. 打开应用 → 自动进入诊断对话
2. 回答第一个问题（您的业务是什么）
3. 配合 AI 追问，深入挖掘
4. 观察右侧画布变化
5. 完成 5 轮对话后，查看商业蓝图
6. 导出您的商业蓝图
```
