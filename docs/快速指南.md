# 商业超体 - 5分钟快速指南

## 我是谁？

我是您的 AI 商业战略顾问。通过对话，帮您发现：
- 您真正值钱的资源是什么
- 客户为什么必须买您的产品
- 您应该怎么做生意

---

## 我需要做什么？

### 只需要做一件事：**回答问题**

我会通过追问引导您思考。您要做的就是：
- 如实回答每个问题
- 深入思考，不要敷衍
- 配合追问挖掘真相

---

## 我会经历什么？

整个过程分 **5 个阶段**：

| 阶段 | 我会被问到 | 我要准备 |
|------|-----------|----------|
| 第1阶段 | 您有什么别人没有的资源？ | 供应链、方法、人脉等 |
| 第2阶段 | 客户不买会怎样？ | 客户的损失和痛苦 |
| 第3阶段 | 您能提供什么服务？ | 交付方式和边界 |
| 第4阶段 | 怎么打败竞争对手？ | 竞争策略 |
| 第5阶段 | 生成商业蓝图 | 获得完整方案 |

---

## 最终我能得到什么？

一份完整的 **「商业蓝图」**，包括：

```
✓ 一句话自我介绍
  "我是XX，我用XX方法，帮XX解决XX问题"

✓ 我的核心资源
  - 我独有的东西是什么

✓ 客户为什么要买
  - 客户的真实痛点

✓ 我该怎么卖
  - 定价策略
  - 交付模式

✓ 怎么建立竞争壁垒
  - 护城河构建
```

---

## 常见问题

**需要多久？**
通常 10-20 分钟，取决于您的业务复杂程度。

**我不懂商业能参加吗？**
可以，我会引导您思考。

**我可以中断吗？**
可以，对话会自动保存，下次继续。

---

## 快速开始

1. 打开程序 → 自动开始对话
2. 回答第一个问题
3. 配合追问深入思考
4. 完成对话后查看商业蓝图
5. 导出保存
